# Push Naseem build 40115 from Termux

Before overwriting anything, make sure your repository has no uncommitted work you need to keep.

```bash
cd ~/noor-adhkar
git status --short
```

Download `Naseem-4.1.0-build-40115-source.zip` into Android Downloads, then import it:

```bash
mkdir -p /tmp/naseem-40115
unzip -o ~/storage/downloads/Naseem-4.1.0-build-40115-source.zip -d /tmp/naseem-40115
cp -a /tmp/naseem-40115/. ~/noor-adhkar/
cd ~/noor-adhkar
```

Review the staged changes. `git add -u` stages tracked source updates; the explicit `git add` includes only the new Worker/config/tests/docs.

```bash
git add -u
git add quran-foundation-worker www/quran-config.js tests/test_mushaf_integration.js tests/test_quran_foundation_worker.mjs IMPLEMENTATION-40115.md BUILD-40115-VALIDATION.md PUSH-40115.md
git diff --cached --stat
git status --short
```

If the diff contains a signing key, credential, local build output, or anything you did not intend to publish, stop and unstage it before committing.

```bash
git commit -m "Naseem 4.1.0 build 40115: Mushaf reader and Quran updates"
git push origin HEAD
```

## Activate Indo-Pak content

The app source includes a secure Cloudflare Worker, but the public app does not contain Quran Foundation credentials. Deploy the Worker from `quran-foundation-worker/`, add `QF_CLIENT_ID` and `QF_CLIENT_SECRET` as Worker secrets, and obtain production API access for the complete Quran. See `quran-foundation-worker/README.md`.

After deployment, set the public Worker URL in `www/quran-config.js`, then commit and push that one configuration change. Never put the client secret or access token in `www/`, GitHub source, or the APK.

The existing Android signing keystore, alias and signing secrets must remain unchanged.
