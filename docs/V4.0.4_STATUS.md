# Naseem V4.0.4 development status

## Implemented in this source update

- Hijri calendar view with offline Intl-based Gregorian/Hijri conversion, adjustable -2 to +2 day correction, and optional AlAdhan API refresh for today's date.
- Dua Library with searchable offline Quranic supplications, transliteration, meaning, references and local favourites.
- Traditional learning profile selector for Hanafi, Shafi'i, Maliki, Hanbali and Ja'fari paths. Selection is informational and does not silently change Salah calculation settings.
- Islamic occasions estimated from the device Hijri calendar, with optional Android local reminders.
- Expanded Salah learning index for foundations, Wudu, Ghusl, preparation, prayer sequence, daily prayers and common questions. Detailed tradition-specific rulings still require qualified review.
- Widget Studio for the existing native Prayer and Tasbeeh widgets, including Tasbeeh label/target configuration and launcher instructions. Widget size is controlled by the Android launcher.
- Glance client with configurable GitHub Pages JSON endpoint, cache, expiry filtering and built-in fallback.
- First-launch setup wizard for tradition, optional location, optional notification permission and completion; existing installations with prior local data are not forced through onboarding.
- Updated emerald startup animation, Home shortcuts, Hijri date and Glance preview.
- Android back-button handling through `@capacitor/app`.
- APK workflow now installs native Java/resources/receivers via `scripts/patch-android.mjs`, applies the themed icon layer, syncs plugins, updates versionCode and uses the stable signing key when it is present.
- Added `glance-feed-template/` for a separate GitHub Pages repository.

## API policy

- Hijri conversion is offline-first; AlAdhan is an optional date cross-check. A local moon-sighting authority may differ.
- Glance is fetched from a public read-only JSON feed and cached.
- Prayer times remain calculated locally by the existing Salah engine. Dua content and learning lessons are bundled offline. No API is added where it would introduce unnecessary dependencies or compromise offline use.

## Release warning

This is a V4.0.4 development build, not a Play Store-ready release. Keep the existing `signing/naseem.keystore` safe and unchanged for compatible sideload updates. It is intentionally not included in source ZIP exports. Before public release, move signing material to protected GitHub secrets / a secure release environment and complete policy, privacy and religious-content review.
